# SekiroSaveFileImporter

把《只狼：影逝二度》(Sekiro: Shadows Die Twice) 的存档文件 `S0000.sl2` **重新绑定到你自己的 Steam 账号**，并自动修正存档所需的 MD5 校验和。

纯 Python 标准库实现，零依赖，跨平台（Windows / Linux / macOS 均可运行）。

参考：[https://www.reddit.com/r/Sekiro/comments/ba44qp/how_to_edit_your_save_file_to_fix_various_issues/](https://www.reddit.com/r/Sekiro/comments/ba44qp/how_to_edit_your_save_file_to_fix_various_issues/)

---

## 为什么需要它

只狼的存档里保存着**创建者的 SteamID64**。游戏每次读档都会把它和当前登录的 Steam 账号比对，不一致就会提示存档无法使用 / 存档损坏。所以：

- 用别人分享的存档 → 读不了；
- 从别的机器、或者非 Steam 版本迁移过来的存档 → 读不了。

只把文件丢进存档目录是不够的，必须把存档里的 SteamID 改成你自己的，并且**重新计算校验和**，否则游戏会判定存档损坏。

## 功能

- 解析 BND4 容器，列出存档内所有 `USER_DATAxxxx` 分块及其校验和状态；
- 扫描并列出存档中记录的 SteamID64（全部出现位置，不只是常见教程提到的那一处）；
- 把 SteamID 批量替换为你自己的 SteamID64；
- 自动重算所有受影响分块的 MD5 校验和；
- 写出文件后再自动复核一次，确保校验和与 SteamID 都正确；
- 只读的 `info` 模式，可用于体检存档而不做任何修改。

## 环境要求

Python 3.8+，无需安装任何第三方库。

## 使用方法

### 1. 查看存档信息（只读，不修改任何文件）

```bash
python sekiro_save.py info S0000.sl2
```

输出示例：

```
分块（* 表示该分块除校验和之外还有实际数据）：
 * 00 USER_DATA000     [0x00000300, 0x00100310) 校验和 OK   非零字节   125506
   01 USER_DATA001     [0x00100310, 0x00200320) 校验和 OK   非零字节       16
   ...
 * 10 USER_DATA010     [0x00a003a0, 0x00a603b0) 校验和 OK   非零字节   174754

存档中的 SteamID64：
  0x00034164  76561198000000000  (SteamID3: 12345678)
  0x00a003d4  76561198000000000  (SteamID3: 12345678)

全部分块校验和均正确
```

### 2. 绑定到自己的 Steam 账号

```bash
python sekiro_save.py convert S0000.sl2 -o S0000_fixed.sl2 --steam-id 76561198000000000
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `-o, --output` | 输出文件路径（推荐，不改动原文件） |
| `--steam-id` | **必填**，你的 SteamID64（17 位数字） |
| `--in-place` | 原地修改，默认会先生成一个 `.bak` 备份 |
| `--force` | 配合 `--in-place`，跳过覆盖确认 |
| `--dry-run` | 只打印将要做的改动，不写文件 |

### 3. 放到游戏存档目录

1. 先备份你自己的原存档；
2. 打开 `%APPDATA%\Sekiro`（资源管理器地址栏直接粘贴即可），进入以你的 Steam 账号命名的子文件夹；
3. 把处理后的文件改名为 `S0000.sl2` 覆盖进去；
4. 启动游戏，选择「继续」读取存档。

> 如果 Steam 云存档开着，覆盖后首次启动可能会和云端冲突，按自己的需要选择保留本地还是云端版本。

## 如何查自己的 SteamID64

- 用 <https://steamid.io/> 之类的在线工具，粘贴你的 Steam 个人主页链接即可查到 `steamID64`；
- 或者打开只狼存档目录 `%APPDATA%\Sekiro`，里面的子文件夹名通常就是你的 SteamID64（少数情况下是 SteamID3，脚本 `info` 输出里的 `SteamID3` 就是后者）。

## 实现原理

`S0000.sl2` 是一个 BND4 容器：

- 文件头 `0x00` 处为 magic `BND4`，`0x0C` 处为分块数量（只狼为 12）；
- 从 `0x40` 起，每个分块头占 `0x20` 字节，其中 `+0x10` 处为该分块的数据起始偏移；
- 容器内存放 `USER_DATA0000` ~ `USER_DATA0011`，每个分块开头 16 字节是**该分块数据区的 MD5**，数据区为 `[分块起始 + 0x10, 下一分块起始)`。改了数据就必须重算这 16 字节，否则游戏提示存档损坏；
- SteamID64 以 8 字节小端整数保存，其高 32 位恒为 `0x01100001`，脚本据此扫描出全部 SteamID 并替换。

## 注意事项

- **动手前一定先备份存档。** 虽然 `convert` 默认只写新文件，但覆盖进游戏目录这一步是你自己做的。
- 网上流传的教程通常只提到 `0x34164` 这一处 SteamID，实际上文件里往往还有第二处（在 `USER_DATA010` 分块内），只改一处仍可能失败 —— 本工具会自动处理全部。
- 该工具只解决「Steam 账号不匹配」和「校验和不对」这两件事。如果源存档来自游戏版本差异较大的版本（例如不同更新版本的破解版），存档结构可能不兼容，这属于版本问题，改 SteamID 无法解决。
- 本工具只修改 SteamID 与校验和，不会改动角色数据、道具、进度等内容。
